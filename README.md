# Activello Theme

Personal project by **Thevin2002**, built on top of an open-source project.

## How to run

This is a WordPress theme. Zip the folder (or copy it to `wp-content/themes/`) and activate it under **Appearance > Themes**.

Tested: all PHP files pass a PHP 8.2 syntax check.
